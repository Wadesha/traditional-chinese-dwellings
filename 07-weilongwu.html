"龙"是什么？

围龙屋的名字来自其半圆形的后围：

  • 龙 = 屋后山脉的走势（风水上的龙脉）
  • 围 = 沿着龙脉延伸的半圆形后围龙屋
  • 整体布局：前方半月塘（蓄水） + 中间方形堂横屋 + 后方半圆形围龙
  • 俯视效果：天圆地方——这是古人宇宙观的建筑表达

标准形制解读

中轴线上（堂横屋）

空间 功能
上堂 祠堂，供奉祖先牌位，最神圣
中堂 家族议事、婚宴寿宴
下堂 门厅、接待男客、禾坪（晒谷场）

两侧（横屋）

  • 东横屋：长子一家
  • 西横屋：次子一家
  • 宗法秩序清晰，居住权明确

后方（围龙）

  • 半圆形层层后移，是家族扩展位
  • 家族人口增加 → 在后方加建一层围龙
  • 仁厚温公祠三围，璼公祠六围——家族越兴旺，围数越多

化胎（花头岃）

围龙与堂横屋之间的半月形空地，卵石铺地，是龙气出口——传统上禁止踩踏、禁止建房，是精神空间。

家族逻辑

围龙屋是以建筑承载家族制度的典范：

祭祖 → 上堂（神圣性）
  │
议事 → 中堂（公共性）
  │
待客 → 下堂（礼仪性）
  │
分住 → 长子东横 / 次子西横（宗法性）
  │
扩展 → 后围龙逐层加建（生长性）
  │
精神 → 化胎花头岃（禁忌空间）

风水的实际功能

风水学不是迷信，它包含了一套选址与环境优化的经验法则：

风水原则 实际功能
靠山选地 背靠山脉可分流山洪，避免直接冲击
水口设置 在河流出口处建塔/树，减速加湿，改善微气候
前后有林 风水林 + 护林保水 + 反射夏季阳光
坐北朝南 冬季最大化利用太阳辐射，通风良好

围龙屋 vs 土楼

对比项 客家围龙屋 福建土楼
开放性 开放式（有大门有围墙，正面不封死） 碉堡式（完全封死，仅一个厚门）
生长方式 生长体（家族人口增加，慢慢加围层） 诺亚方舟（一次建成，关门守家）
防御性 次一级（围屋 + 围墙） 顶级（厚墙、无窗、射孔、防火门）
核心功能 家族聚居 + 宗法秩序 防御外敌 + 聚族自保
