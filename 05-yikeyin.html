"一颗印"这个名字，正是营造学社刘致平先生 1938 年在昆明测绘时命名的——因其平面方正如印章。

"三间四耳倒八尺"

这是昆明工匠的祖传口诀，精确描述了一颗印的标准形制：

        ┌───────────┐
        │  倒座（8尺） │  ← 进深仅 8 尺（约 2.4m）
        ├─┬─────┬─┤
        │ │     │ │
        │ │ 天井 │ │     ← 方小天井 3m × 3m
        │ │ 3×3m │ │
        │ ├─────┤ │
        │ │ 正房 │ │     ← 三间面宽 12m，进深较大
        │ │ 三间  │ │
        └─┴─────┴─┘
       左耳房    右耳房
      （各两间）（各两间）
  • 三间：正房面阔三间，总宽约 12m
  • 四耳：左右各两间耳房，共四间
  • 倒八尺：倒座进深仅八尺（约 2.4m），是压缩出来的
  • 小天井 3×3m：方寸之间，通风采光排水

高原气候应对

昆明海拔约 1900m，年均温 15°C，年日照 2500+ 小时，昼夜温差可达 30°C——一颗印精准回应：

高原挑战 一颗印对策
强日照 窄天井 + 深腰檐（大小厦）遮阳，天井终日不被直射
昼夜温差 30°C 厚土坯墙 50–70cm，巨大热惰性缓冲温度波动
年均温 15°C 无固定朝向，可依山势灵活布置
平地稀少 二层紧凑布局，竖向发展

大小厦烟囱效应 —— 高原自然空调

    正房腰檐（大厦，出檐 80cm）
      │
      │   ← 太阳加热天井空气
      │     热空气变轻上升
      ▼
    ┌─┴───┴─┐
    │  天 井  │     ← 3m×3m，热空气从上方排出
    └─┬───┬─┘
      │   │
    耳房腰檐（小厦，出檐 40cm）

结果：夏季室外 30°C → 天井内 22°C

高低台基三高差

一颗印用四级台基体现礼制 + 解决排水 + 创造自然台阶：

        正房   +1.20m（最尊贵）
    ┌────┴────┐
    │ 耳房 +0.75m │
    ├───────────┤
    │ 倒座 +0.30m │
    ├───────────┤
    │ 天井  ±0.00m │  ← 最低点，四面排水汇聚
    └───────────┘
  1. 天井最低：雨水自然汇集排出
  2. 倒座 +30cm：比院落高，防雨水倒灌
  3. 耳房 +75cm：稍高
  4. 正房 +120cm：最尊贵，视野最好

这不仅仅是空间秩序，也是一套被动排水系统。

抗震奇迹

一颗印采用穿斗木架 + 厚土墙的弹性组合：

  • 穿斗式木构架不依赖榫卯紧密咬合，地震时可微动耗能
  • 厚土墙（50–70cm）提供侧向刚度
  • 1996 年丽江 7.0 级地震，昆明周边一颗印民居屹立不倒
